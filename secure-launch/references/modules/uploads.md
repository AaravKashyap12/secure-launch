# Uploads

Load only controls selected for actual project features. Defaults below follow the approved priority policy; a demonstrated day-one exposure can move a later item forward. Record why.

## I04 — Accept uploads without granting execution

- **Why:** An uploaded file should remain data rather than execute or overwrite files.
- **Applies:** Uploads or archive import.
- **Default priority:** Before launch.
- **Who / approval:** Agent after plan.
- **Implementation:** Bound size/type/path, rename safely, store outside executable/public paths unless deliberate.
- **Local verification:** Fake files, misleading extensions and traversal names denied; valid fixture accepted.
- **Stack pointers:** use the detected stack via [stack index](../stacks/README.md); turn the proof above into a specific command and working directory before approval.
- **Sources:** [O13](../sources.md#o13), [O10](../sources.md#o10).
