# Other hosting and identity providers

Read date: 2026-09-27.

Detect the provider, product and app version before choosing documentation. Vercel, Netlify, AWS, Auth0 and Clerk features differ by plan and topology. Account state cannot be proven from a source file; prepare user steps, and label unavailable provider docs.

Local proof: Use local token/config mocks. Real provider settings and DNS/email verification stay with the user; never invent keys, plan entitlements or DNS records.
